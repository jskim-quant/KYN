# 금융 엔진 (대차대조표·월 현금흐름)

UI와 분리된 순수 TypeScript 모듈. 위치: `lib/finance/`. 테스트: `__tests__/finance.test.ts`.
기존 세금 모듈(`lib/tax.ts`)은 수정하지 않고 어댑터에서 재사용한다.

## 구현 범위
| 단계 | 상태 |
|---|---|
| 기존 구현 점검 | 완료 (아래 점검 결과) |
| 데이터 모델·대차대조표 | 완료 — 개인별/가족 연결, 내부대출 상계 |
| 월 단위 현금흐름·시나리오 이벤트 | 완료 — 매각·차입·가족 이전·지분 증여 |
| 레버리지·결정론적 스트레스 | 일부 — LTV(자산별)·최소현금·최대부족액·변동금리 경로만. DSCR·충격 조합·만기집중도는 미구현 |
| 확률적 시뮬레이션 | 미구현 |
| 전략 비교(가중점수·Pareto) | 미구현. 기존 코드에 없어서 새로 만들어야 함 |
| UI 통합 | 미구현. 어떤 화면에도 연결하지 않았다 |

## 사용법
```ts
import { convertLegacy, runCashflow } from '@/lib/finance';
const conv = convertLegacy(assets, members, { startMonth: '2026-10', horizonMonths: 120, macro });
const result = runCashflow({ ...conv.base, events: [/* 매각·차입·이전 */] });
// conv.excludedAssets / conv.warnings 는 반드시 화면에 노출한다.
```
실행: `npx vitest run`

## 처리 규칙
- 금액은 원 단위 정수. 억·만원 변환은 어댑터 경계에서만 한다.
- 월별 순서: 가격 갱신 → 수익(소득·임대·배당·매각대금) → 의무 지급(생활비·세금·담보해제 상환·대출 상환) → 계획된 거래 → 잔액 확인.
- 현금 부족은 기록만 한다(자동 대출·매각 없음). 의무 지급 직후 부족은 같은 달 차입금으로 가려지지 않는다.
- 순자산은 실제 납부한 세금만 반영한다. 엔진은 세법을 계산하지 않고, 호출자가 넣은 세액을 지정한 월에 지급한다.
- 법인 지분은 지분가치로만 잡는다(법인 보유자산 연결 없음).

## 기존 구현 점검 결과
- 스택: Next.js 14 + Supabase. 세금 계산은 `lib/tax.ts` 한 파일(약 4,100줄, 단위 억·부동소수).
- 소유 모델: 앱은 "자산 1개 = 소유자 1명, 시가 = 그 사람 보유분"으로 동작한다. DB의 `asset_shares`, `corp_shares`, `past_gifts`, `debts` 테이블과 `ownership_share_pct` 컬럼은 앱 어디에서도 쓰지 않는다.
- 부채 모델: 자산당 대출 1건(`loan_amount`)뿐. 대여자·만기·상환방식·가족 내부 대출 구분이 없다.
- 현금흐름: `calcAnnualCashflow`는 단일 연도. `monthly_rent`·`vacancy_rate_pct`·`maintenance_cost`를 무시하고, 생활비·원금상환이 없다. 금융자산은 성장률과 수익률이 겹쳐 이중 계산될 수 있다.
- 가중점수·Pareto: 없다.
- 계산 로직이 UI에 섞여 있다: `scenarios/page.tsx`(약 2,900줄)에 `buildS1`~`buildS6` 등, `strategy/page.tsx`(약 2,900줄).
- 소유자 미지정 자산이 실제로 존재한다(스크린샷 기준). 어댑터는 제외하고 목록으로 알린다.
- 기존 테스트 45개는 통과한다. 세법 규칙 자체의 정확성은 이번에 검증하지 않았다.

## 가정과 한계 (어댑터)
- 입력 소득은 세후 현금유입으로 간주(근로·사업소득 세금 모형 없음). 생활비 입력이 없어 0으로 계산하며 경고한다.
- 보유세는 오늘 기준 연액을 고정 명목금액으로 납부. 재산세 토지 9월, 그 외 7·9월 절반씩, 종부세 12월, 임대소득세 5월(근사). 종부세는 인별 합산이 아니라 소유자 비례 배분 근사.
- 기존 대출은 만기·상환방식이 없어 이자만 납부하고 만기 연장으로 가정. 기타 부채는 금리 0%로 들어가 이자가 과소 계산된다.
- 매각 소요기간·매각비용은 입력이 없을 때 사용자 가정 기본값(부동산 6개월·0.5% 등)을 쓴다.
- 임대료는 명목 고정. 전세보증금·기타 채무는 부채로 반영하지 않는다.
- 담보한도는 차입자 지분 담보가치 × 사용자가 지정한 최대 LTV.
